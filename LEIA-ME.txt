SITE DE TESTES — CRM KRAFT (GITHUB PAGES)

Este projeto não precisa de instalação, Node.js, VS Code ou servidor.

Arquivos:
- index.html
- style.css
- script.js

COMO PUBLICAR NO GITHUB PAGES

1. Entre em github.com e crie um repositório novo.
2. Pode chamar, por exemplo:
   crm-kraft-laboratorio
3. Marque o repositório como Public.
4. Envie os 3 arquivos deste ZIP para a raiz do repositório.
5. No repositório, abra:
   Settings > Pages
6. Em "Build and deployment":
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
7. Clique em Save.
8. Aguarde alguns segundos/minutos.
9. O GitHub mostrará o endereço público do site.

IMPORTANTE

Este é um laboratório visual com dados fictícios.
Ele NÃO está conectado ao Supabase e não altera o CRM real.

Isso é intencional: permite testar interface, botões, paginação,
filtros e ideias sem risco para o sistema principal.

GitHub Pages aceita sites estáticos como este. O CRM real, que usa
Next.js/API/Supabase, deve continuar no Vercel.
